# 営業時間外の予約（店がイレギュラーで入れる）

2026-10-17 に入れた。宗本さんの要望:

> イレギュラーで営業時間外に予約をジム側で手入力で入れられる機能を考えて

決めたこと（宗本さん「1、数えない 2、入れられる」）:

1. 時間外の予約は **1日の上限（`daily_booking_limit` / `daily_total_limit`）に数えない**。
   店があえて足した枠なので、その日のお客様の予約枠を減らさない
2. **定休日にも入れられる**（定休日は1日中が「時間外」）

## 使い方（店側）

予定表 →「代理予約」→ いちばん上の **「営業時間外・定休日に入れる（イレギュラー）」** を ON。

- 日付: 定休日・指名した担当の休みの曜日も選べる（ON の間は日付の制限を外す）
- 時刻: 営業時間の**外にかかる開始時刻だけ**を「開店前／閉店後」に分けて並べる。
  定休日は「定休日（終日）」に 0:00〜24:00 の全部
- 「予約する」を押すと日時の確認（「営業時間外の予約です：10月18日（日） 07:00〜08:00。…」）が出て、
  ボタンが「この時間で入れる」に変わる。**もう一度押すと入る**。営業時間外は打ち間違いに
  気づきにくいので2段にした（時刻や日付を選び直すと1段目に戻る）
- 予定表には **「時間外」の印**（月のアイコン）が付く。PC の表・スマホの一覧・週のタイムライン

## 仕組み

| どこ | 何をしているか |
|---|---|
| `bookings.outside_hours`（boolean, 既定 false） | 時間外の印 |
| `guard_booking_outside_hours_flag`（BEFORE INSERT/UPDATE） | 印を付けられるのは **owner / trainer とサービスロールだけ**。お客様が付けようとしたら黙って false に戻す（エラーにしない＝古い端末を壊さない）。付いている印は UPDATE で外れない |
| `guard_booking_staff_shift`（GB002） | 印付き＋入れた人がスタッフ（またはサービスロール）なら**担当のシフト外でも通す** |
| `tenant_day_booking_count` | 印付きを数えない。`tenant_day_closed`・`tenant_day_total_reached` はこれを呼ぶので一緒に外れる |
| `get_tenant_closed_days` | 件数をその場で数えているので、同じく印付きを除く |
| `useDayReception.bookedCountOn` | 予定表の「n/4件」も印付きを除く |

### もともと DB は営業時間を見ていない

営業時間・定休日は**画面だけ**が見ている。代理予約はもともと GB006（受付しない時間帯）・
GB007（その日の受付停止）・GB003（予約回数の制限）も通る（お客様の自己予約だけに効く）。
時間外の代理予約を止めていたのは **GB002（担当のシフト外）だけ**だった。

### 変わらないもの

- **重なり（GB001）は今まで通り効く**。時間外でも、同じ担当・同じ時間の二重予約は入らない
- **お客様のコースの回数には数える**（実際に1回受けているので。「今回 4/8回目」のまま）
- キャンセル規定・通知（`notify_booking_created`）は普通の予約と同じ

## お客様側

- 予約一覧・カレンダーには普通の予約として出る
- **変更はできない**。押すと「このご予約はジムが特別にお取りした時間のため、日時の変更はジムにご連絡ください」。
  時間外の枠はお客様の画面に無いので、変更先を選ばせると営業時間内に移ってしまう
- キャンセルは普通にできる（規定も同じ）

## 予定表の行

予定表の行はもともと営業時間から作っていた（`businessGridMinutes`）。それだけだと時間外の予約が
表に出ないので、**表示中の予約の開始時刻を行に足す**（`withBookingStartTimes`）。
刻みに乗らない開始時刻の予約（営業時間を変える前に入った予約など）も、これで表に出る。
予約の無い行は今まで通り出さない（PC の表は `hasAnySession` で畳んでいる）。

## やっていないこと

- **日付をまたぐ予約**（23:30〜翌0:30 など）。予定表は1日単位で並べているので、終了が 24:00 を
  超える開始時刻は出さない
- **体験・ドロップイン**は対象外（公開フォームから入るもの。店が入れるのは代理予約だけ）
- **入れたあとで印を付け外しする画面**は無い。間違えたら消して入れ直す
