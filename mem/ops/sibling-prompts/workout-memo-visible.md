# 記録の「その日のメモ」を一覧で常時表示してください

店側のカルテにある日々の記録（workouts 相当のテーブル。機能フラグで無効なら
このプロンプトは対象外なので確認して報告だけしてください）には日単位のメモ
（notes 列）がありますが、**編集画面を開かないと読めません**。実店舗から
「過去のセッションをスクロールしているだけで常にメモが見えるようにしてほしい」と
要望が出た改善です。

## 仕様（決定済み）

- 記録一覧（日付ごとのカード）の種目リストの下に、その日のメモを常時表示する。
  概要タブに直近の記録サマリーがあるならそちらにも同じものを出す
- メモの拾い方は**編集画面へ引き継ぐロジックと同じ規則**にする（ジムボードは
  「その日の行のうち notes が空でない最初の行」。保存時に全行へ同じ値が入る構造
  だった。このアプリの保存側を確認して**同じ規則**で拾うこと——ずれると一覧と
  編集画面で違うメモが出る）
- 改行保持（whitespace-pre-wrap）・長文は折り返し・メモの無い日は何も出さない
- お客様側アプリが notes を読んでいないなら変更しない（店側専用の欄）。
  読んでいるなら扱いを確認してから判断

## 検証

- 見張りテスト: 一覧の表示箇所数と「編集画面と同じ拾い方の規則」をソースで固定。
  表示ブロックを消す変異で赤を確認
- DB 変更なし。ゲートグリーン → PR → マージ
