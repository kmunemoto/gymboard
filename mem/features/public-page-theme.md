# 公開の予約ページ（体験・ドロップイン）の色をジムごとに固定する（2026-09-25）

## 要望

宗本さん（Safari で開いた自分のジムの体験予約ページのスクリーンショット。見出しがオレンジ）:

> 私のジムの体験予約ページの色はオレンジ変えてティファニーブルーに固定して

## なぜオレンジだったか

公開ページ（`/trial`・ドロップイン）は独自の色を持たず、アプリ全体の色
（`--primary` / `--accent` / `--accent-2`。`gym-gradient` / `accent-gradient` もこれ）で描いている。
その色は**見ている端末の「テーマカラー」**（設定画面で選ぶ。localStorage。`src/lib/themeColor.ts`）。

- 初めて来るお客様の端末には設定が無い → 既定（ティファニー系。`index.css` の初期値）で見える
- テーマカラーを変えたスタッフ・会員の端末 → その色で見える（宗本さんの Safari はアンバー）

つまり**お客様には元々ティファニー系で見えていた**が、見る端末によって色が変わる作りだった。
`tenants.primary_color` は公開ページでは使われていない（`--tenant-color` に入るだけで、参照箇所なし）。

## 直し方

- `tenants.public_theme_color`（text・NULL 可）: テーマカラーの id（例 `teal-soft`）。
  CHECK で `'色-トーン'` の形だけ受ける。**NULL（既定）は今まで通り**
- `get_tenant_public` が返す（返り値の型が変わるので DROP → CREATE → **GRANT を貼り直す**）
- `src/hooks/usePublicPageTheme.ts`: 値があるときだけ、ページを開いている間
  - 色をその色にする（端末のテーマカラーより優先）
  - すりガラス・背景写真のクラス（`theme-glass` / `theme-photo` / `bg-tone-dark`）も外す
  - 離れたら元に戻す（同じタブでアプリに戻ったとき、その人の設定が生きているように）
  - 知らない値は何もしない（今まで通りに倒す）
- 体験・ドロップインの両ページで使う（宗本さんの依頼は体験ページだが、同じ種類の公開ページなので揃えた）

### 本番（2026-09-25 適用済み）

- マイグレーション `20260925010000_public_page_theme.sql` を適用（適用前に本番の関数本体が
  リポジトリと一致することを md5 で確認）
- **御所南だけ** `public_theme_color = 'teal-soft'`（＝以前からのティール＝アプリの既定色＝ティファニー系）。
  ⚠️ ジムの UUID と値は**マイグレーションに書かない**（リポジトリは public）。本番で直接 UPDATE した
- 他の19ジムは NULL（変化なし）
- 未ログイン（anon）で `get_tenant_public` を呼び、御所南は `teal-soft`、他のジムは NULL が返ることを確認

### 設定画面は無い

いまはジムの設定画面から選べない（依頼は御所南だけ）。他のジムでも使うなら、
設定画面に「予約ページの色」を足す（テーマカラーの64色ピッカー `ThemeColorSwitcher` の選び方を流用できる）。
