# アクティブ顧客の数え方（ジムごとの設定）

## 要望（2026-09-23 宗本さん）

> アクティブ顧客って何を基準に数えてるの？ 本当に今通っている人だけの数字を出して欲しい。
> 僕の場合は次回の予約が入ってない人はアクティブ顧客に数えないで欲しい。
> その辺、設定できるようにできる？ジムごとに

それまでの「アクティブ顧客」は**在籍している全員**（休会・退会にしていない人）で、
実際に来ているかは見ていなかった。本番の自社ジムで 42名と出ていたが、
内訳を出すと次のとおりだった（2026-09-23 12:58 時点）:

| | 人数 |
|---|---|
| 通っている（今日以降に予約あり） | 23名 |
| 予約待ち（最近来たが次の予約が無い／登録したばかり） | 4名 |
| 離れている（14日以上来ていない・一度も来ていない） | 15名 |
| 合計＝在籍 | 42名 |

## 設定（`tenants`）

| 列 | 値 | 既定 |
|---|---|---|
| `active_client_basis` | `enrolled`（在籍の全員）／`next_booking`（次回予約あり） | `enrolled` |
| `follow_up_after_days` | 3〜90（画面では 7/10/14/21/30） | 14 |

**既定は今まで通り。** 回数券の店のように1回ずつその都度予約する運用では、
次の予約が無いのが普通なので「次回予約あり」だと通っている人まで数字から消える。
設定画面は「表示設定」の統計カードのON/OFFの直後（`ActiveClientsSettingsCard`）。

## 判定（`src/lib/activeClients.ts`）

ひとりを必ず1つに分ける。

| 分類 | 条件 |
|---|---|
| coming（通っている） | 今日以降に予約がある。**今日来る人は、来たあとも今日いっぱい** |
| awaiting（予約待ち） | 次の予約は無いが、最後の来店（または登録）から目安日数が経っていない |
| away（離れている） | 次の予約が無く、目安日数以上来ていない／一度も来ていない |
| suspended（休会） | どこにも数えない |

「今日いっぱい」にしたのは、セッションが終わるたびに数字が減ると
朝と夜で違う数字が出て「壊れた」と見えるため。

### 🔴 「離れている」＝「フォローが必要な顧客」

ホーム画面の「フォローが必要な顧客」は、この判定の away を**そのまま**出している。
それまでは画面に別の判定（`INACTIVE_DAYS = 14` 直書き）があった。数字と一覧を
別々に数えると、片方だけ直されて食い違う（このリポジトリで何度も起きた形）。
目安日数も同じ1つの設定を使う。

### 🔴 日数の数え方は旧実装と1日も変えていない

- 最後の来店から: 来店日が**終わってから**何日経ったか（`floor((今 − 来店日 23:59:59 JST) / 1日)`）
- 登録から: `floor((今 − 登録時刻) / 1日)`

既定の店（20店中19店）で、フォロー一覧に出る人が**1人も変わらない**ようにするため。
`src/test/activeClients.test.ts` が**旧コードをそのまま写して**、400人 × 6つの時刻
（深夜・昼・夜・日をまたいだ直後など）× 目安 7/14/30日で突き合わせている。
境目を暦日の差にするだけで18件、`>=` を `>` にするだけで13件落ちる。

### 唯一の意図的な違い: プロフィールの無い空アカウント

profiles の行が無い会員は、画面側（`useAllCustomerProfiles`）が created_at に
「いま」を入れていた。旧実装はそれを信じて「登録したばかり」とみなし、
**何か月も前の空アカウントがフォロー一覧に一度も出なかった**。
新しい判定は `has_profile` を見て「離れている（一度も予約なし）」に入れる。
本番で該当するのは自社ジムの2件だけ（どちらも予約0件。6/10 と 8/11 に作られ、
1件は一度もログインしていない）。profiles は `handle_new_user` トリガーが作るので、
行が無いのは作成に失敗した異常なアカウント。

## 画面

「次回予約あり」の店だけ、次が出る（在籍の全員の店は今まで通りで、何も増えない）:

- 統計カードの見出しは**どちらの数え方でも「アクティブ顧客」だけ**。
  最初は「アクティブ顧客（次回予約あり）」＋下に「予約待ち ◯名 ・ 離れている ◯名」を
  出していたが、2026-09-24 に宗本さんの指示で外した（「下の文字いらない。アクティブ顧客のみでいい」）。
  次の予約が無い人は、下の2つの一覧に出る
- 「次の予約待ち」の一覧（最後の来店が古い順＝急ぐ順）。
  それまで、最近来たのに次を取っていない人は**どこにも出ていなかった**
  （フォロー一覧は目安日数以上来ていない人しか出さないため）

一覧の見た目は `ClientFollowUpList` に1本化した（フォロー一覧と予約待ちで同じ形）。
