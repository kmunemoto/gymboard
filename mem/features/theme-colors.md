# テーマカラー 64色（2026-09-24）

## 要望

宗本さん（設定画面のスクリーンショットを添えて）:

> テーマカラーを64色にしてください。このまま色を選ぶシステムだと64色難しいので、
> 色を選ぶデザイン考えて。いい案、任せます

お客様側・店側の設定画面で共通（`src/components/ThemeColorSwitcher.tsx`）。
端末ごとの好み（localStorage）で、テナントの設定ではない。

## 形: 16の色 × 4つのトーン

| | |
|---|---|
| 色（16） | ローズ・レッド・オレンジ・アンバー・マスタード・ライム・グリーン・ティール・シアン・スカイ・ブルー・インディゴ・バイオレット・マゼンタ・ピンク・グレー |
| トーン（4） | ビビッド（鮮やか）／ソフト（やわらか）／くすみ（くすみカラー）／ディープ（深い・暗め） |

id は `${色}-${トーン}`（例: `pink-dusty`）。

## 選び方（画面）

64個の丸を並べると、スマホでは1つが指より小さくなる（1列8個で約30px）。そこで2段にした。

1. **色（4×4）**: 1枚の札に、その色の4トーンを縦縞で見せる。**64色がひと目で見える**。
   選んでいる札には枠、選んでいるトーンの縞にチェック
2. **トーン（4つ）**: 選んだ色の4トーンを大きな丸で。名前つき

- 色を替えても**トーンはそのまま**（くすみが好きな人は、くすみのまま色だけ替えられる）
- どちらも押した瞬間にアプリ全体の色が変わる（見比べながら選べる）
- 上に「ティール・ソフト」のように選択中の名前を出す

## 🔴 色は OKLCH から計算で作る（`src/lib/themePalette.ts`）

HSL で全色に同じ「彩度・明度」を入れると、黄色は明るすぎて白い文字が読めず、
青は暗すぎる（HSL の明度は目に見える明るさと揃っていない）。
OKLCH の L（見た目の明るさ）をトーンごとに揃え、色相 H を16通りに変えて作る。
画面に出せない鮮やかさ（sRGB の外）になるときは、C を出せるところまで下げる。

| トーン | L | C（狙い） |
|---|---|---|
| ビビッド | 0.60 | 0.19 |
| ソフト | 0.65 | 0.10 |
| くすみ | 0.58 | 0.065 |
| ディープ | 0.42 | 0.10 |

グレーだけは C を小さく（0.012〜0.045）。
`--primary` は色相を5度戻して少し暗く、`--accent-2` は8度進めて少し明るく
（以前の6色と同じ関係。見出しのグラデーションに使われる）。

### 見張り（`src/test/themePalette.test.ts`）

- 新しく作った58色: 白い文字との比が `--primary` / `--accent` で 3:1 以上、`--accent-2` で 2.5:1 以上
- 64色のどの2色も、OKLab で 0.02 以上離れている（見分けられる）
- ディープがどの色でもいちばん暗い

くすみの C を 0.05 にしたとき、ローズとレッドのくすみが 0.015 まで近づいた。
色相の間隔（ローズ 8° ／レッド 30°）と C（0.065）はそれで決めた。**動かすならテストを回すこと。**

## 🔴 以前からの6色は値を1文字も変えない

選んでいた人の見た目が勝手に変わらないように、6色は以前の値のまま（`LEGACY_COLORS`）
64色の中のいちばん近いトーンの枠に置いた。

| 以前の id | 今の id |
|---|---|
| teal（既定） | `teal-soft` |
| blue / violet / rose / amber / green | `*-vivid` |

**ティールだけソフト**。最初はビビッドに置いたが、計算で作ったソフトとの差が 0.008 しかなく、
同じ色が2つ並んだ。ビビッドには計算で作った鮮やかなティールを入れた。

- 端末に保存されている古い id（`"teal"` 等）は `resolveThemeColorId` が読み替える
- 既定（`teal-soft`）は index.css の初期値と同じ色。起動時は上書きしない（今まで通り）
- 6色は白い文字との比が 3:1 に届かないものもある（既定のティールの `--primary` は 2.47）。
  見た目を変えないことを優先して、そのまま残した

テストは6色の値を**別に書き写して**突き合わせている（`OLD_SIX`）。

## 変異（すべて赤になることを確認済み）

ティールをビビッドに戻す／6色の値を1つ変える／古い id の読み替えを外す／
色を替えたらトーンがビビッドに戻る／ソフトを明るくしすぎる（L 0.72）／くすみの色みを減らしすぎる（C 0.04）
