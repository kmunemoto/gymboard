宗本さん「予約画面の一番上にも出せるようにして」。伝えたかったのは「次回分のご予約も前もって取れる・
お支払いは毎回1回目のトレーニングの日」。それまで予約画面の上に出せたのは「キャンセルについて」

## 何がどこに出るか

| 欄（店の設定 → 予約のルール） | 列 | 出る場所 |
|---|---|---|
| 予約画面のご案内（この機能） | `booking_page_note` | 会員の予約画面（日時を選ぶ画面）のいちばん上・見出し「ご予約について」 |
| ご来店前のお願い | `pre_visit_note` | 予約完了の画面・ホームの「次回の予約」 |
| キャンセルについての案内 | `cancel_policy_body` | 予約画面の上とキャンセル確認（「当日のときだけ」なら当日のキャンセル・変更の確認だけ） |

- 🔴 体験予約・ドロップイン（未ログインの公開ページ）には出さない（`get_tenant_public` に足していない）
- 🔴 既定は NULL＝何も出さない。例は入力欄の薄い文字だけ（上流が文言を代弁しない）
- 長さは300字（DB の CHECK と `BOOKING_PAGE_NOTE_MAX`）。書けるのはオーナーだけ（tenants の UPDATE のポリシー）
- 特定のジムの文はリポジトリに書かない（本番で直接入れる）
