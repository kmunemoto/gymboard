## 書くときの注意

### 言語は ja に固定されている

`src/test/setup.ts` で `localStorage.setItem("i18nextLng", "ja")` している。これが無いと
jsdom の `navigator.language`（en-US）で英語が選ばれ、さらに `@/lib/i18n` の
「保存言語を後から読み込んで再適用する」非同期処理がテスト実行中に割り込んで、
**同じテストが実行タイミングで通ったり落ちたりする**（実際に8回中1回落ちた）。

### jsdom は CSS を評価しない

`hidden md:flex` などで出し分けているデスクトップ用とモバイル用は、**両方DOMに出る**。
`TrainerSidebar` はラベルが異なる（例: ダッシュボード / ホーム）ので、それぞれで確認している。

### Radix のアコーディオンは閉じている間、中身をDOMに出さない

`TrainerGymSettings` のトグルを見るには、先に該当カテゴリーのトリガーをクリックして開く。

### Supabase を叩く子コンポーネントはスタブにする

画面構造の検証が目的なら、`TrainerPlanManager` などはスタブに差し替えてよい。
ただし**検証対象そのもの**（招待コードカードの配置など）は、位置が分かる目印に置き換える。

### モックが本物の壊れ方を再現できているか確かめる

`realtimeChannelCollision.test.tsx` には「固定名を使うと確かに throw する」ことを
確認するテストを入れてある。これが無いと、モックが甘くなったとき
残りのテストが「何も検証していないのに緑」になる。

### 追加したら変異テストで確認する

実装をわざと壊してテストが落ちることを確認してから入れている。落ちないテストは
書いていないのと同じ。実際にこの方法で、純粋関数テストでは捕まえられない回帰
（開いているタブを残す例外）が1件あることが分かった。
