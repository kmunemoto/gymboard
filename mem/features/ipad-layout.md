# iPad で、アプリに戻ると中身だけが左に細く寄る（2026-11-26）

宗本さん（iPad のオーナー画面のスクショ）「ipadのみ、再度アプリを開くと画像みたいに右に寄る。
この現象の原因を調べて直して」。

## 見え方

- ヘッダー（画面の上に固定）は横いっぱい。左のサイドバーも普通に出る
- 中身（ダッシュボードのカード・本日のスケジュール）だけが、サイドバーのすぐ右に**細い列**で出て、
  右側が大きく空く。数字が「3…」「1…」に切れ、バッジが縦書きのようになる

## 原因

`src/index.css` が html・body・#root の幅を **`max-width: 100vw`** で抑えていた。

iPad のアプリ（WKWebView）は、アプリに戻ったときに **vw（画面の幅の単位）だけが古い幅のまま**
残ることがある（スクショから測ると約480pt。実際の画面は約810pt）。

- メディアクエリ（`md:` 以上＝768px 以上でサイドバーを出す）は**本当の幅**で効いていた
  → サイドバーが出ている。もし画面の幅そのものが 480 だったら、サイドバーは隠れて下のナビになるはず
- 画面に固定（`position: fixed`）のヘッダー・サイドバーは本当の画面に合わせて出る
- 普通の流れで並ぶ中身（#root の中の `<main>`）だけが、480 − 240（サイドバーの `ml-60`）の幅に押し込まれる

ブラウザ（810×1080）で html・body・#root を 480px に抑えると、スクショとそっくり同じ見た目になるのを確かめた
（中身の幅 240px・数字が切れる・バッジが縦になる）。

## 直し方

ページ全体の幅は **vw で抑えない**。`max-width: 100%`（親の幅）にした。ブロック要素は何もしなくても
画面の幅いっぱいになるので、上限は親の 100% で足りる。横にはみ出さない守り（`overflow-x: hidden`）は残した。

- ダイアログの `max-w-[90vw] sm:max-w-md` は直していない。iPad の幅（640px 以上）では `sm:max-w-md` が効くので vw を使わない
- 🔴 **ページ全体・外枠の幅に vw（`100vw`・`w-screen`）を使わないこと**

見張り: `src/test/viewportWidthUnits.test.ts`（html・body・#root の幅に vw が無い、index.css に 100vw が無い、
オーナー・お客様の画面の外枠に `w-screen` が無い。変異3件を赤で確認）

## 確かめられていないこと

クラウドのコンテナでは iPad の WKWebView を動かせないので、**「vw が古いまま残る」こと自体は実機で見ていない**
（スクショの寸法と、メディアクエリが本当の幅で効いていることからの判断）。アプリは次のビルドから。
ビルド後に iPad で「アプリを閉じて開き直す」を何回か試して、寄らないことを確かめてもらう。
