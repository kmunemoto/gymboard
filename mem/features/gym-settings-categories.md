## 構成（TrainerGymSettings.tsx）

- `settingsView: SettingsCategory | null` の内部状態だけで遷移（URL は変えない）。
  開閉時に `window.scrollTo({ top: 0 })`
- 一覧 = 招待コード＋**ジムボードの利用プラン（請求・TrainerBilling）[flag]**＋グループ見出し＋
  行（アイコン・ラベル・説明・chevron）＋最下部にログアウト・引き継ぎ/閉店・アカウント削除
- **各セクションの JSX・保存ロジックは一切変えていない**。ガード
  `{settingsView === "x" && (…)}` で出し分けるだけ（2026-08-23 の組み替えは
  マーカーコメント単位の機械的な移動で実施）

| グループ | カテゴリー | 中身 |
|---|---|---|
| ジム | 基本情報 | 表示名・ロゴ・連絡先メール・電話・LINE・Google口コミ[flag] |
| ジム | スタッフ管理 | TrainerStaffManager（**行ごと owner 限定**） |
| ジム | プラン管理 | お客様向けの契約プラン（TrainerPlanManager）だけ。請求は入れない（下の 2026-10-08） |
| 予約 | 営業時間・受け入れ枠 | 営業時間・時間帯別の同時受け入れ数・スタッフ別シフト |
| 予約 | 予約のルール | 回数の制限・受付しない時間帯・事前アンケート・予約ポリシー |
| 予約 | 体験予約[flag] | リンク・案内文・料金（フラグOFFなら行ごと消える） |
| 案内・表示 | メール・通知 | メールの案内文・朝のサマリー |
| 案内・表示 | 表示・テーマ | 表示設定17項目・言語[flag]・テーマカラー・背景画像 |
| サポート | 使い方ガイド | TrainerHelpGuide |
| サポート | 運営への要望 | OperatorFeedback |

i18n キーは `settings.trainer.cat.*`（5言語）。

必要がある（TrainerGymSettings.test.tsx の `openDisplayCategory()` 参照）。
2026-08-23 の変更で3ファイル・10本をこの形に更新した:

- TrainerGymSettings.test.tsx … 表示トグル系は「表示・テーマ」を開いてから。
  「招待コードが最上部」「一覧→開く→戻る」の構造テストも追加

## 2026-10-08: ジムボードの利用プラン（請求）をカテゴリーから出した

宗本さん（「プラン・お支払い」のページに、お客様向けのプランとジムボードの料金プランが
縦に並んでいるスクリーンショット2枚）:

> Stripe決済のプラン、それだけは独立させて設定欄に招待コードの一番下にそのまましまわず記載して

- `TrainerBilling`（ジムがジムボードに払うプラン。Stripe 決済）を、一覧の**招待コードのすぐ下**に
  開いたまま置いた（カテゴリーの行にしない）。見出しは今まで通り「プラン・お支払い」
- カテゴリー「プラン・お支払い」は中身がお客様向けのプランだけになったので**「プラン管理」**に改名
  （説明「お客様向けの契約プランの作成・編集」）。`clientDetail.noPlans`「ジム設定のプラン管理から
  追加してください」が元からこの名前で案内していたので、それとも揃った。中の見出し
  「プラン管理」はページ名と重なるので外した（キー `settings.trainer.planManage` も削除、5言語）
- ヘルプ「5. プランのご契約方法」の手順2も「ジム設定を開くと、お客様の招待のすぐ下に」に直した
- 表示する相手は今まで通り（全員。購入ボタンはオーナーだけ、は `TrainerBilling` 側の判定のまま）
- 副次効果: 決済から戻ったときの「お支払い手続きが完了しました」（`?billing=success` を

  いまはジム設定を開いた時点で出る（戻った直後の画面はホームのまま。`?tab=billing` で
