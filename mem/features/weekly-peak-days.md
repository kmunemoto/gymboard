# 週に何日かだけ、会員の1日の上限を増やす

2026-10-22 に入れた。宗本さんの要望:

> 私のジムの1週間に受ける予約の数を2つ増やします。基本一日5枠までにして、週に2日5枠が
> 埋まったら他の曜日は枠の上限を自動で4枠までにする。なお、体験予約はこれに影響されません

確認したこと:

1. 1週間は **月曜〜日曜**
2. 会員が5人入った日も、**合計の上限（体験込み・`daily_total_limit`）はそのまま**。
   会員5人の日は体験は入らない。体験は「5人の日」の数には入らない

## 仕組み

設定は `tenants.weekly_peak_limit`（多い日の人数）と `tenants.weekly_peak_days`（週に何日まで）。
どちらかが NULL、または人数が `daily_booking_limit` 以下なら**今まで通り**。

```
その日の会員の上限 =
  その週（月〜日）の「ほかの日」で、会員が weekly_peak_limit 人以上の日が
    weekly_peak_days 日未満 → weekly_peak_limit（例 5）
    それ以上              → daily_booking_limit（例 4）
```

例（4 / 5人 / 週2日）: 月・火に5人入ったら水〜日は4人まで。火にキャンセルが出て4人に戻れば、
ほかの日がまた5人まで取れる（その場で数え直すだけで、記録は持たない）。

- 数え方は今まで通り（`tenant_day_booking_count` と同じ）: キャンセル済み以外・
  **店の代理予約も営業時間外の予約も数える**（時間外は 2026-10-23〜）。体験・ドロップインは数えない
- 止まるのは**会員の自己予約だけ**（GB007）。店の代理予約・体験は今まで通り通る
- 「その日だけ上限を外す」日は上限なし。**5人の日の数にも入れない**
- 手で止めた日（赤）でも、5人入っていれば5人の日として数える（DB の件数どおり）

## 🔴 2026-10-28: 曜日ごとの上限と、数え方の変更

曜日ごとに会員の上限を決められるようにした（`mem/features/weekday-booking-limits.md`）。
あわせて「増やした日」の数え方を **「weekly_peak_limit 人以上の日」→「その曜日の上限を超えて入った日」**
に改めた（もともと多い曜日を数えない・上限4/増やした日6 で5人の日を数え忘れていた）。
上限5・増やした日6 のような1人差なら同じ答え（本番で全ジム一致を確認）。

## 🔴 計算は DB の1か所

`tenant_member_day_limits(tenant, from, to, exclude)` が日ごとの上限と件数を返す。
次の3つが全部これを使う:

| 関数 | 何に使うか |
|---|---|
| `tenant_day_closed` | 会員の自己予約のガード（GB007） |
| `get_tenant_closed_days` | お客様の予約カレンダー・予定表の「受付終了」 |
| `get_tenant_daily_limit_left` | その日に予約しているお客様だけに見せる残り枠 |

- 範囲の両端を含む週をまるごと数える（カレンダーが水曜からでも、その週の月・火を数える）
- 予約の変更では、動かす予約を数えない（`p_exclude_booking_id`）

画面の `src/lib/weeklyPeak.ts` は、予定表の「n/◯人」を出すための**同じ計算の写し**。
変えるときは両方そろえる（`src/test/weeklyPeakDays.test.tsx`）。

## 🔴 同時に別の日の5人目が来る

「5人の日」があと1日のときに、月と水の5人目が同時に来ると、どちらも「まだ1日」と数えて
両方通ってしまう。`guard_booking_day_closed` で**その店のその週**の
`pg_advisory_xact_lock` を取ってから数える（会員の自己予約だけ。トランザクションの終わりで外れる）。

## 設定画面

ジム設定 → 予約のルール → 1日の上限人数 →「週に何日か、上限を増やす」。
「週に◯日まで」と「◯人まで」の両方を選ぶ。人数は1日の上限より大きいものだけ選べる。
日数は1〜6（7日すべてなら1日の上限そのものを上げればよい）。

🔴 **効いていない週の設定は「増やさない」と見せる**（2026-10-26）。古い版の画面で1日の上限だけを
上げると、週の設定が残る（本番で「1日の上限5・週の設定5人/2日」になっていた）。人数が1日の上限
以下なので DB の判定では効いていないが、そのまま画面に出すと保存のたびに「人数を選んでください」で
止まっていた。保存すれば NULL に片付く。保存値の判定は `weeklyPeakSaveValues`。

## 運用の記録
