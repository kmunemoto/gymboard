# 店側の予定表: 予約をメニューごとに色分けする（2026-11-19）

宗本さん（ジム側の予定表のスクショを添えて）:

> 私のジムだとトレーニングとピラティスみたいな、トレーニングに合わせて予約の色変えれる？
> このジム側のスケジュールの画面

色の決め方を「メニューごとに選べる」「自動で色分けだけ」の2つで聞いて、**「自動で色分けだけ」**に決まった
（設定は増やさない）。

## 決まり

| 予約 | 色 |
|---|---|
| いつものメニュー（担当のいない先頭＝トレーニング） | **今の色のまま**（テーマ色＝`bg-accent`） |
| メニューの無い予約（`menu_id` が NULL。古い予約・店が入れた予約など） | 今の色のまま |
| ほかのメニュー（マシンピラティス・ヨガ） | 自動で別の色 |
| ブロック（休み） | 今まで通り（灰色の点線） |
| メニューが1つ以下の店 | **何も変わらない**（11/19 時点でメニューがあるのは御所南だけ） |

- 色は `src/lib/menuColors.ts` の `menuColorMap`。端末で選んでいるテーマ色（localStorage）と**同じトーン**で、
  色相がテーマ色から**60度以上**離れた色を、離れている順に当てる（themePalette の64色から作るので、
  白い文字との比 3:1 以上がテストで保証されている）。グレーは使わない
- テーマ色は端末ごとなので、メニューの色も端末ごとに違う（同じ端末では毎回同じ）。
  例: ローズ（御所南の宗本さんの端末）→ マシンピラティスはティール。ティール（既定）→ ローズ寄りの色
- 当てる順は「受付中のメニューが先・同じなら並び順」。外しているヨガ（並びはピラティスより先）に、
  いちばん見分けやすい色を取られないため
- 🔴 オプション付き: トレーニングは今まで通り `bg-primary`＋左の帯＋「＋」。ほかのメニューは
  **塗りはメニューの色**で、左の帯＋「＋」で示す（2026-09-03 の「オプション付きは色で区別」を、帯で残す）
- 色は `hsl(185, 30%, 45%)` のカンマ区切りで書く（空白区切りはテストの jsdom が読めず、色のテストが
  空どうしの比較で素通りしていた。WebView はどちらも読める）

## 出す場所

- 週の予定表（`WeekTimelineView`）のカード。説明（title）にメニュー名も付けた
- 日の予定表: PC の表のカードと、スマホの一覧の頭文字の四角（`useMenuColors` の `menuCardStyle`。
  `TrainerSchedule` は qualityRatchet の上限（1300行）に近いので、色の計算はフックに出してある）
- 凡例（`MenuColorLegend`）: 表示モードの切り替えのすぐ下。**色の付いたメニューの予約がその週に1件でもあるときだけ**出す
  （トレーニングだけの週は今まで通り何も足さない）。その週に無いメニュー（ヨガ）は出さない

DB は変えていない（見た目だけ）。Web は 11/19 に Publish 済み。iOS は **1.9.8**（Actions #191・`eadebb7`・11/20 アップロード。1.9.7 は欠番）から。Android は次の手元のビルドから。
