# 兄弟アプリ向けプロンプト集の使い方

上流 merge の運用は 2026-08-03 に終了した（`mem/ops/vertical-fork.md`）。
以後、機能はコードではなく**プロンプトで運ぶ**。各ファイルの**水平線（---）から下**を、
そのアプリ（セッコツボード・ストレッチボード・ピラボード・ゴルフボード）の
セッションに丸ごと貼る。

## 書き方の約束（新しいプロンプトを足す人へ）

- **決定事項は固定**し、ファイル名・関数名・SQLSTATE の採番・文言は
  「向こうの現物に合わせて読み替えさせる」書き方にする
- ジムボードで**実際に踏んだ地雷**を必ず載せる（同じ穴に落とさせない）
- 検証の作法（変異検証・本番の3段構え・ROLLBACK）もプロンプト内に含める
- フォーク後のジムボード専用機能に依存する箇所は「あれば繋ぐ」の条件付きにする
