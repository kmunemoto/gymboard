# トレーニング記録のメモを一覧で常時表示（2026-08-22）

宗本さんの要望:「その日のセッションのメモが、編集画面を開かないと読めない。
過去のセッションをスクロールしているだけで常に見える状態にしてほしい」。

- カルテ（TrainerClientDetail）の**記録タブの過去記録一覧**と**概要タブの
  直近トレーニング**の両方で、日付カードの種目の下にメモを常時表示する
- メモは**日単位**。保存時にその日の全行（workouts.notes）へ同じ値が入るので、
  表示は「その日の行のうち notes が空でない最初の行」から拾う
  （openEdit の existingMemo と**同じ規則**。ずれると編集画面と一覧で違うメモが出る）
- 改行保持（whitespace-pre-wrap）・長文は折返し。メモが無い日は何も出ない
- お客様側アプリは notes を一切読んでいない（トレーナー専用欄）ので変更なし
- 見張り: workoutMemoAlwaysVisible.test.ts（2件・表示除去の変異で赤を確認）
- DB変更なし・文言追加なし（ロケール変更なし）。Web は Lovable の Publish、
  アプリは次のネイティブビルドで反映
